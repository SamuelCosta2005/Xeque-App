# Xeque-App
Aplicação multiplataforma para gerenciamento de clubes de xadrez, desenvolvida em Flutter, com Firebase/Firestore como backend. Projeto focado em simplicidade de uso, gerenciamento de jogadores, torneios e partidas, com versões Web e Android.
# Tarefas futuras
Segurança: implementar regras mais restritivas no Firestore e autenticação adequada caso o projeto evolua de um uso interno para uma aplicação pública em maior escala.
